## 视觉方向

沿用 `docs/UI_STYLE_GUIDE.md` 的已确认方向：暗木与黑铁承托，旧纸承载局部详情，黄铜建立选中与操作层级，玉色表达成长，暗朱红表达危险。低饱和、暖光、克制纹样，中文正文采用当前 Noto Sans CJK SC 的可读字形方向。

计时器采用古铜刻度表盘，数字与剩余进度同时可见；它是玩家在短局中最稳定的视觉锚点。正文与数字的明度高于纹理和装饰。

## 交互设计

- 竖屏探索：顶部常驻气血、等级、铜钱、修为细线和计时器；右侧保留设置、角色、情报入口。武学收进角色面板，主体区域用于看路与遭遇；滑动移动，不绘制固定摇杆。
- 横屏探索：信息贴四角，武学可紧凑展开，移动摇杆位于左下安全区。
- 武学三选一：横屏便于并排比较；本次竖屏提案采用三行选择，点选展开详情，再确认。每项直接展示本次属性收益；选中项展示秘传双流派分段进度与选后差距。
- 洞穴商店：两列货架先显示图标、名称、收益和价格，选中商品在下方展示详情并购买。售罄用文字和轮廓区分。窗口开启时隐藏移动控件，底层不接收输入。
- 自动战斗：中央交锋区优先，玩家构筑集中在技能栏，不添加手动攻击或闪避按钮。
- 普通战斗延续主倒计时；洞穴使用蓝灰暂停符号和“主时间暂停”；最终 Boss 使用独立累计用时，不显示主地图压力进度。
