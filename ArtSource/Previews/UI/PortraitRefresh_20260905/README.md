## 设计决策

沿用 UI_STYLE_GUIDE 的暗木、黑铁、旧纸、古铜和低饱和状态色。框架、文字和图标在正式接入时分层。
竖屏以 540×960 逻辑布局为设计基准，实际 PNG 尺寸以文件为准；板图用于比较，不等于等尺寸导出。
探索采用顶部紧凑信息组，底部保留滑动移动；无常驻摇杆，无主动攻击或技能释放按钮。
武学图标承载重数和自动触发状态。连战磨砺归入成长摘要，完整属性按需展开。
三选一采用纵向卡片，装备突出前后比较，商店双列并在模态期间拦截地图输入。

## 时间语义

- 普通战斗：继续同一主倒计时。
- 洞穴：同一主倒计时转蓝灰暂停态，并说明洞内活动仍继续。
- 中期首领：保留暂停的主时间，同时展示独立交锋计时；胜利后恢复探索。
- 最终 Boss：用独立正向计时替代主倒计时及压力环。
- 武学选择、真正暂停菜单：明确全局暂停。
