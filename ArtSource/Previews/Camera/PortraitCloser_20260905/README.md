## 运行与复验

无需新建 GameObject、挂载脚本或手动绑定 Inspector/Prefab/UI。
打开 MainPrototype，Game View 选择 Portrait 540×960，进入关卡2并选择起手武学即可。
建议移动观察出生点、桥面和建筑附近，并分别拾取两处望气灵物，确认视野密度符合预期。
