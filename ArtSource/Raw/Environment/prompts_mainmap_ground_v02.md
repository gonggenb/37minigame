# Main Map Ground v02 Prompts

Generation mode: built-in `imagegen`, `Generate`.

## Grass

```text
Use case: stylized-concept
Asset type: production seamless albedo texture for a Unity 2.5D wuxia roguelite main-map ground
Primary request: create one square, perfectly tileable muted grass-and-moss ground texture viewed straight down
Style/medium: hand-painted low-poly game texture, restrained Chinese wuxia picture-book atmosphere, matte gouache brushwork, compatible with simplified KayKit-style scenery
Composition/framing: uniform full-frame texture swatch with no focal point, no horizon, no perspective; opposite edges must connect seamlessly in both axes
Lighting/mood: neutral albedo only, soft and even, no directional lighting, no baked shadows, calm weathered countryside
Color palette: low-saturation grey moss green, muted olive and sage, tiny restrained warm-ochre soil flecks
Materials/textures: broad soft grass masses, sparse small grass strokes, subtle earthen undertone, medium-to-large texture scale so it remains quiet at gameplay camera distance
Constraints: exactly one square ground texture; seamless tile; low contrast; no alpha; no text; no watermark
Avoid: realistic photography, high-frequency noise, obvious repeating motifs, flowers, large leaves, stones, paths, footprints, objects, characters, borders, gradients, vignette, highlights, specular shine, cast shadows
```
