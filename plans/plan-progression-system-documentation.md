# 当前技能与养成系统文档整理

## 需求描述

基于项目当前代码、CSV 配置、场景接入状态、UI、Prefab、美术资源和自动化测试，完整梳理现有技能系统与局内养成系统，生成可供后续开发、Unity Editor 接入和维护使用的养成系统文档。

文档需要明确区分：

- `MainPrototype.unity` 当前实际使用的旧原型养成链路。
- Domain/Application/Architecture 中已经实现的新架构养成链路。
- 武学、装备、修为、等级、奖励候选与角色属性之间的职责边界。
- 一次升级从奖励发放、经验结算、暂停、候选生成、UI 展示、玩家选择到属性生效的完整脚本调用链。
- 当前 UI、组件、场景、Prefab、美术资源的实际接入情况与 Unity Editor 待绑定内容。
- 当前能力、测试覆盖、已知限制和后续维护入口。

## 实现方案

1. 阅读项目规则、玩法说明、技术约束、架构重构计划和相关现有文档。
2. 从技能与养成相关脚本、CSV、测试、场景序列化引用和资源文件出发，建立文件与职责清单。
3. 分别追踪旧原型与新架构中的修为获取、等级提升、三选一、刷新、武学升阶、装备应用和属性刷新链路。
4. 对照 UI View/Presenter、IMGUI、Prefab、场景和美术目录，确认哪些内容已实现、哪些已绑定、哪些仍是占位或待接入。
5. 在 `docs/` 下新增当前技能与养成系统文档，使用职责表、调用链、状态差异、数据流和文件索引表达现状。
6. 运行针对性的静态检索与已有测试，核对文档中的类名、方法名、配置字段和测试结论。
7. 仅更新文档与本计划，不修改运行时代码、场景、Prefab、美术或配置数值。
