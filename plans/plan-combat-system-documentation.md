# 当前战斗系统文档整理

## 需求描述

基于项目当前代码、配置、场景接入状态和自动化测试，完整梳理现有战斗系统，生成可供后续开发与维护使用的战斗系统文档。

文档需要明确区分：

- `MainPrototype.unity` 当前实际使用的旧原型战斗链路。
- Domain/Application/Architecture 中已经实现的新架构战斗链路。
- `MainPrototype_Architecture.unity` 当前已接入和仍待 Unity Editor 手动绑定的部分。
- 普通战斗、洞穴战斗和最终 Boss 战对主地图计时的不同影响。
- 当前能力、配置来源、测试覆盖、已知限制和后续维护入口。

## 实现方案

1. 阅读项目规则、玩法说明、技术约束和架构重构计划。
2. 从遭遇入口开始，沿游戏流程、战斗管理、角色属性、奖励、武学、装备、UI 和计时服务追踪实际调用链。
3. 对照场景序列化内容、CSV 数据和 EditMode 测试，确认代码是否已接入、规则是否有测试保护。
4. 在 `docs/` 下新增当前战斗系统文档，使用职责说明、流程图、公式、状态差异和文件索引表达现状。
5. 仅更新文档与本计划，不修改运行时代码、场景、Prefab 或配置数值。
