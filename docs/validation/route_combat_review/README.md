# 区域奖励、小怪特点与结算复盘

本次只优化这三项；第二关仍为 22 个老怪点位和 18 个新怪点位，三条时间规则保持。

## 区域目标

- 练武场：击败两个不同的普通/精英目标，额外提升一门已学、未满重的武学一重。
- 营地：击败两个不同的普通/精英目标，额外获得一件未持有装备，沿用装备自动替换判断。
- 洞穴：本局首次完成真实洞穴事件并离开，给与主流派存在秘传联系的另一流派起手武学补修，最多两重。
  优先已有深度较高的相邻流派；实际门槛达成时由已有秘传系统自动解锁。不是随机发放无关联武学。
- 三项均每局只能领取一次；无可升级武学/无可领取装备/跨派起手均满重时补偿 20 铜钱。
- 重复目标不增加进度；撤离未完成洞穴、调试空入口、重复进入商人均不能刷取传承。
  商人只有交易，没有完成事件，不触发本项。其他正常完成的洞穴事件可触发。
- 旧的近中远 1/1.5/2 倍修为铜钱和远端宝箱升重保持；区域奖励额外发放。
- 第二关起手页预告三种收益。地图新增三个复用原样式的区域牌，靠近显示奖励与本局进度；
  标牌在运行时自动建立，不需要新图集或 Inspector 绑定。练武场 10 普通+2 精英，营地 8 普通+2 精英。
- 点位采用第二关既有 PC 编号映射；移动或重排点位时须同步 PingchuanRouteCatalog 并重新验证。

## 三类小怪特点

仅第二关普通遭遇从视觉配置获得特点，不作用于其他关卡、精英、洞穴或 Boss。

| 类型 | 规则 | 对应外观 |
| --- | --- | --- |
| 重撞 | 第一次攻击尝试的攻击力为 140%，随后恢复；闪避可消耗此次首击 | 铁獠山猪 |
| 毒咬 | 命中后施加 3 次余毒，每战斗秒一次；再次命中刷新次数，不叠层也不推迟下次毒发 | 赤练蛇妖 |
| 机关护甲 | 开场获得最大气血 12% 的护甲，所有玩家伤害来源均可削减 | 老青竹机关傀及 ballista/rider 兼容外观 |

余毒伤害为 max(1, 怪物攻击×25% - 玩家防御×25%)，继续经过玩家现有减伤与护盾。
毒伤不跨战斗保留；退出、取消和重开清空。暂停冻结战斗计时。地图等级旁显示特点，战斗敌方状态栏显示实时状态。
三类复用已有攻击动作；本次未新增美术或独立技能条带。

## 结算与重试

- 横竖屏使用同一份滚动复盘：普攻、剑气、连环剑、毒伤、反震的前三项贡献占比；护盾抵消、有效吸血回血；最后对手与剩余气血；区域奖励进度及武学。
