# 战斗伤害小幅随机

## 行为与文件

- 修改 `Assets/Scripts/Battle/BattleManager.cs`：集中定义 `DamageVarianceRatio = 0.05f`，双方普攻（含暴击）、剑气、连环剑、反震和每次毒发分别乘以 0.95–1.05 的随机倍率。
- 修改 `Assets/Scripts/Battle/BattleManager.FinalBoss.cs`、`BattleManager.MidBoss.cs`：狐火各段、中期 Boss 各段攻击使用相同浮动规则。
- 新增本记录。没有修改场景、Prefab、UI 样式、运行时中文文案或显示倍率。

每份伤害在原有攻防、暴击与减伤计算后、护盾吸收前只抽取一次；扣血、吸血、战报与飘字继续使用该结果。展示仍保留整数和千分位，减少的是固定整百、整千尾数，不添加小数点。满血、攻击面板与固定恢复等属性不会随 UI 重绘随机跳动。最低基础伤害 1 也参与浮动，成为 0.95–1.05；闪避和完全吸收仍为零伤害。

## 验证

Unity 6000.5.4f1 完成脚本编译，Console 无 error；`git diff --check` 通过。

在 Editor 内创建并清理临时组件，调用实际 C# 方法验证，测试后恢复 Unity 随机状态：

- 固定种子 906 抽样 10,000 次基础伤害 12，范围 11.4000607–12.5998793，平均 11.9987122；对应显示均值约 11,999，原值为 12,000。
- 前八次显示：12,274 / 11,942 / 12,195 / 11,844 / 12,019 / 12,149 / 11,824 / 12,568。
- 玩家普攻、敌人普攻、必暴击、剑气、连环剑、反震、毒发、狐火和中期 Boss 攻击各 128 次：全部处于预期范围，显示值各有 90–122 种，未致死且无护盾时实际扣血与报告伤害一致（浮点误差容限 0.0001）。
- 完全护盾吸收和必闪避各 128 次均未扣血，零伤害保持为零。

另在现有 MainPrototype 场景 Play Mode 注入测试属性并切换真实战斗阶段，运行实际 Update 与战斗协程：

- 普通战斗：主时间 60 降至 52.581，发生 21 次攻击，战报样例为 9,354。
- 洞穴战斗：主时间保持 50，攻击序列从 21 增至 64。
- Boss 阶段：主时间保持 50，独立 Boss 时间从 0 增至 13.297 秒。

三条时间规则均通过定向回归。测试结束退出 Play Mode，恢复临时后台运行设置；未保存或重建场景。以上不代表完整路线试玩、全流派胜率平衡或真机视觉验收。

## 运行与复验

无需创建 GameObject、挂脚本、绑定 Inspector 或拖入 Prefab/UI。打开 `Assets/Scenes/MainPrototype.unity`，进入 Play Mode，开始一局并接触敌人，观察连续普通命中不再固定显示整千数；获得毒掌或剑气后检查对应伤害，进入洞穴和 Boss 检查暂停与独立计时。

未完成：本轮没有执行移动设备视觉验收、WebGL 构建或长期胜率统计。随机会轻微改变个别战斗的击杀次数与耗时，平均基础伤害保持原值。
