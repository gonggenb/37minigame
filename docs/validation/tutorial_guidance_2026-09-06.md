# 第一关首次接触引导

## 实现

- 开场保留“你只有30秒!”，补充移动和接触互动说明；点击“开始探索”启动教学。
- 药草、宝箱、敌人、洞穴首次接触先说明用途，确认后执行原互动；药草数值、敌人和宝箱收益读取被接触对象的配置。
- 首次升级先解释修为与武学，再回到原有三选一。战斗胜利触发升级时保留待选奖励，不提前返回地图或进入总结。
- 各主题每次教学只显示一次，重玩教学重新显示；关卡2不触发这些说明。教学洞穴当前固定为秘藏，未增加商店或其他教学地图内容。
- 阅读使用 `TutorialLearning` 阶段，暂停教学计时、屏蔽移动及底层 HUD/摇杆，不改全局时间倍率。对象在确认前保持未消耗。
- 弹窗主按钮确认，背景点击不会关闭；0.25 秒防误触。设置窗口可覆盖说明，关闭后恢复；跳过会清理待执行互动并进入既有难度提示。

## 运行与复验

无需创建 GameObject、挂载额外组件或绑定 Inspector / Prefab / UI 引用。打开 `Assets/Scenes/MainPrototype.unity`，进入 Play Mode，从关卡选择进入第一关；也可直接运行 `Assets/Scenes/TutorialLevel.unity`。

1. 确认开场后依次走向南方药草、西方宝箱、东方洞穴和北方敌人，检查首次说明及确认后的真实互动。
2. 在说明中等候、打开关闭设置、尝试拖动背景，检查不耗时、不移动、不误关闭。
3. 升级时确认说明、选择武学，检查返回原玩法；教学结束或跳过后进入第二关，不再显示本次教学说明。
4. 重玩第一关，检查说明重新出现。

三条时间规则保持：普通战斗主时间继续，洞穴战斗主时间暂停，最终 Boss 独立计时。教学阅读暂停发生在战斗开始前或升级选择阶段。
