# 战斗外放特效收束检查与修正

日期：2026-09-24。状态：`InEngineQA`，不代表手机实机或最终用户美术批准。

## 问题与证据

初检在 Unity 6000.5.4f1 的真实 Play Mode 中完成。原有 690 项功能检查通过、运行错误为零，
但截图显示飞行尾弧、掌印和扩散圈同时占据较大范围；角色收招后敌人周围仍有完整外放效果。
这属于视觉时序和范围问题，功能测试通过不能代替观感验收。

- 外放层固定持续 0.68 秒，另加动作时长 22% 的释放延迟。最快 0.14 秒动作结束后仍可残留约
  0.571 秒（代码推算，非逐帧测量），并允许最多三个实例重叠。
- 剑气绘制三道错位弧线；掌法命中圈、毒雾和碎片叠加；重斩地面环与裂纹扩张幅度较大。
- 发射起点每帧从移动中的人物框重算，人物回位或下一次前冲能牵动已经飞出的特效。
- 旧截图探针只重新定位人物动画时间，未同步特效时间，不能拿旧截图当作严格同相位对比。

初检报告及部分原始截图在 [before](before/)，保留原样。

## 修改

修改 `Assets/Scripts/UI/BattleScreenController.HeroSkillVfx.cs`：

- 外放层在本次动作的 22% 释放，持续该动作时长的 72%，在 94% 收尾；高速出手同步缩短。
- 飞行达到目标后才开始该外放层的命中反馈，飞行本体迅速淡出，不在敌人身上长时间停留。
- 剑气收成一道紧凑弧与同中心高光；掌印缩小，移除全包围飞行圈和破甲额外碎片；掌法命中圈、
  毒雾范围及重斩冲击圈、裂纹均收紧。
- 首个可见帧锁定发射点，目标随敌人移动；横竖屏切换后不绘制旧坐标特效。容量仍限制为三个。
- 不修改伤害、出手冷却、技能触发概率、主角帧图、普通攻击图内效果及绝学演出。

修改 `Assets/Scripts/Debug/HeroAttackPlayModeProbe.cs`：

- 截图时同步采样人物与本次外放特效，避免只倒回人物动作。
- 使用真实技能结算，补充剑气/毒掌/惊鸿、普通/高攻速、横/竖屏共 12 组检查和 24 张飞行/命中截图。
- 在真实时间推进后检查每组动作结束无尾效；真实高攻速协程停止后再确认旧特效清理。

修改 `docs/hero_attack_pack.md`：更新当前行为，并标明早期固定时长记录已被替代。
新增本目录的说明、初检证据、修正后证据。既有 `hero_attacks`、`hero_ultimates`、
`hero_ultimate_poses` 下由原探针输出的报告/截图也随本次回归刷新；没有重新生成美术素材。

## 验证结果

- Unity 编译通过；[修正后报告](after/playmode_report.json)：`success: true`，715 项通过，`runtimeErrors: []`。
- 普通战斗真实协程继续扣主时间；洞穴战斗主时间保持；最终 Boss 战推进独立时间、主时间保持。
- 高速技能仍出现，实例数受限；停止出手 0.2 秒后无旧外放层。取消战斗清空、敌方出手/毒伤不覆盖
  玩家出招、普攻随机与大招回归也通过。
- 已目视核对横竖屏飞行/命中样本，外放层体积与范围收紧，人物和命中点仍清楚。
- 结束后 Unity 已退出 Play Mode，活动场景仍为 `MainPrototype`，场景未脏、没有保存测试夹具。
- 没有新增运行时中文文案，没有平台构建；未重建 WebGL，未进行手机触控/设备帧率验收。

## 运行、复现与手动绑定

不需要创建 GameObject、挂载脚本、拖入 Prefab/资源或修改 Inspector。
打开 `Assets/Scenes/MainPrototype.unity` 进入 Play，使用剑气诀、毒砂掌、惊鸿一式等武学碰怪观察。
自动复现：从该场景的编辑态执行 `37 MiniGame/Validate Hero Attack Pack Play Mode`。
该入口临时调整 Game View，测试后恢复并退出 Play；报告在 `docs/validation/hero_attacks/playmode_report.json`，
新增截图以 `Cohesion_` 开头。本目录 `after` 为本次通过结果快照。
