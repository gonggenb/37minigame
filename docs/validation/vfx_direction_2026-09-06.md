# 招式与特效朝向核对

2026-09-06，针对第二关第 30 秒 Boss 战中的招式朝向反馈。

## 问题与修正

剑气图集 `spr_vfx_sword_qi_6f_v01.png` 的弧形前缘朝左，但玩家位于左侧、目标在右侧。
旧代码仅将特效中心从玩家移到敌人，始终使用正向 UV，造成“移动向右，图案朝左”。
无影连环剑的两次爆发复用相同图集，也继承了错误朝向。

现以施放者和目标的横坐标与图集原生方向计算是否翻转。仅翻转当前切片的 UV，保留帧序、纹理资源和所有伤害事件。
中期 Boss 刀光使用同一判断，施放者传入 Boss、目标传入玩家；当前布局下保持图集原有的左向。
角色 Sprite 的 `flipHorizontally` 不再被当作特效方向依据。

| 项目 | 施放者 / 受作用方 | 核对结果 |
| --- | --- | --- |
| 剑气诀与装备剑气 | 玩家 → 敌人 | 修复蓝色剑气前缘，现在朝右 |
| 无影连环剑 | 玩家 → 敌人 | 两段剑气统一朝右，爆发落于敌人 |
| 镇关·震岳斩 | Boss → 玩家 | 保留原有左掠，接入目标方向判断 |
| 横刀连破第一段 | Boss → 玩家 | 保留左向水平斩 |
| 横刀连破第二段 | Boss → 玩家 | 保留右下至左上的上挑斩 |
| 玄甲固守 | Boss 自身 | 保持环绕 Boss，不向玩家投射 |
| 狐火 | 最终 Boss → 玩家 | 代码确认移动终点为玩家；通用爆点没有单向刀锋 |
| 毒雾、破甲、反震 | 敌人受作用 | 代码确认落点为敌人，径向特效不作整体翻转 |
| 玩家护盾、恢复 | 玩家自身 | 代码确认附着玩家，保留自身效果 |
