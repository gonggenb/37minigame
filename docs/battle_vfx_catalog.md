# 武学与战斗特效账本

2026-09-25 已完成全类特效横竖屏 Play Mode 复查，修正暂停、毒雾遮挡、中期 Boss 落点、血域斩击与毒层越界，见 [复查记录](validation/combat_vfx_audit/README.md)。

## 表达规则

- 瞬时命中：最多持续 `0.82` 秒，优先显示真正改变本次结算的技能。
- 战斗展示按 Unity 游戏时间推进，设置暂停时动作、外放、绝学、飘字与展示冷却同步冻结。
- 持续状态：低透明循环，不遮挡角色动作和伤害数字。
- 纯属性被动：不单独爆光，通过攻击频率、闪避、回血、护盾等结果反馈体现。
- 同源机制共用轮廓：装备触发的剑气、毒、破甲与武学使用同一 VFX，避免“一套机制多套语言”。

## 装备与 Boss

- 装备提供的剑气、毒层、破甲、开战护盾和闪避回血，分别复用同名机制的 VFX。
- 暴击加速装备不单独播放特效，避免与暴击爆点重复。
- 狐火连击显示三枚朱橙飞行冲击；妖甲护体继续使用金色 Boss Aura、染色和横幅；残血狂暴继续使用红色 Aura、染色和横幅。
