# 主地图区域与敌人内容表

## 当前目标

当前主地图为 64 × 56 的短局探索尺度，通过区域地标、边缘装饰和不同敌人定位提升精细度。
现有扩图与构筑规划见 [构筑、怪物、山洞与地图扩展计划](build_map_expansion_plan.md)。

| 区域 | 视觉识别 | 主要敌人方向 |
| --- | --- | --- |
| 中央驿路 | 十字土路、桥、集市、村舍 | 山贼、巨鼠、刀客 |
| 东郊村落 | 房屋、果树、围墙、村门 | 快剑、机关傀、流寇 |

| 南矿山路 | 矿洞、寨墙、采石堆、关楼 | 毒刃、赤骑、岩窟守卫 |

## 路线引导

- 出生点现在使用中央驿路广场作为明确的起步节点，四个出口均放置实体路牌。
- 东侧路牌提示“快剑 / 破甲”，西侧提示“毒掌 / 续航”，北侧提示“铁壁 / 防御”，
  南侧提示“装备 / 高收益”；路牌同时展示风险层级，但不锁定玩家路线。
- 完成起手武学选择后，HUD 状态提示会推荐一条与当前核心相配的首路线。该提示只负责降低
  开局理解成本，玩家仍可根据附近敌人、宝箱和洞穴即时改道。
- 区域标签只在主地图阶段和近距离显示，离开中央近圈后自动收起，避免持续遮挡战场感知信息。

地图装饰遵守 [2.5D 武侠绘本美术规范](art_style_guide.md)：场景保持低对比和低反射，敌人轮廓优先于背景细节。

## 密度控制

- 道路中心和遭遇触发器周围保留清楚的移动空间。
- 树木、岩石和墙体优先布置在区域边缘与道路转折处。
- 模型只承担视觉作用，不增加复杂 MeshCollider。
- 本次按明确需求在内圈/中圈道路空档补充 6 个普通敌人；继续增加前应先实玩验证路线拥挤度。
