# 深度构筑、云游商店与图标计划

> 实现状态（2026-08-04）：五流派 20 武学、5 组跨派秘传、15 件装备、8 件遗物、
> 6 种消耗品与 10 格固定库存商店已经接入。开局从五个流派起手式中随机展示三选一；
> 绝学当前采用三重成长并在对应流派累计 5 重后进入候选。最终生成 70 个透明独立 icon，
> 覆盖武学、秘传、装备、遗物、消耗品、商店功能和洞穴事件，已不再依赖同图兜底。

## 1. 目标

本方案在快剑、毒掌、铁壁基础上增加影身、血刀两条路线，并通过跨流派秘传、固定规则
奇物和可规划商店，让玩家在短局内形成更多不同构筑。

商店参考《杀戮尖塔》的信息组织思路：同屏陈列不同类别商品、价格持续可见、有限货币
迫使玩家取舍、提供一次性整理构筑的服务。只参考选择结构，不复制其卡牌、美术、角色、
布局尺寸或具体数值。

所有可购买、可选择、可触发的内容必须拥有独立 icon。正式版本不允许不同武学或装备
长期共用替代图标。

## 2. 构筑内容总量

| 构筑层 | 目标数量 | 单局获得量 | 作用 |
| --- | ---: | ---: | --- |
| 主流派 | 5 | 选择 1 个起手，可混入 1 个副流派 | 决定基本战斗方向 |
| 武学 | 20 | 5–7 重 | 形成核心、协同和绝学 |
| 跨派秘传 | 5 | 0–2 | 奖励明确的双流派组合 |
| 固定装备 | 15 | 穿戴 3 件 | 改变攻击、护盾、毒伤等触发规则 |
| 江湖奇物 | 8 | 最多持有 2 件 | 提供地图、商店或整局规则变化 |
| 即服丹药 | 6 | 0–3 | 当场补给或小幅永久成长 |

装备继续使用固定设计，不增加随机词条、词缀洗练或大型装备系统。

## 3. 五条主流派

每条流派由起手核心、两个协同武学和一门单重绝学组成。普通武学最多三重，绝学只有一重。

### 3.1 快剑

| 武学 | 定位 | 核心效果 |
| --- | --- | --- |
| 剑气诀 | 起手核心 | 按命中次数追加无视防御的剑气 |
| 疾剑式 | 频率协同 | 提高攻速，更快触发命中类效果 |
| 破甲掌 | 对甲协同 | 命中持续削减本场敌人防御 |
| 无影连环剑 | 绝学 | 触发剑气后，下一次攻击间隔缩短 35% |

### 3.2 毒掌

| 武学 | 定位 | 核心效果 |
| --- | --- | --- |
| 毒砂掌 | 起手核心 | 命中叠毒，毒伤每秒结算 |
| 百毒心经 | 上限协同 | 提高毒层上限和单层伤害 |
| 吸星诀 | 续航协同 | 普攻和毒伤转化为恢复 |
| 化功毒雾 | 绝学 | 毒达到上限时引爆一次额外伤害并保留毒层 |

### 3.3 铁壁

| 武学 | 定位 | 核心效果 |
| --- | --- | --- |
| 铁布衫 | 起手核心 | 提高气血与防御 |
| 金钟罩 | 护盾协同 | 每场战斗开始获得随防御成长的护盾 |
| 反震诀 | 反击协同 | 受到实际伤害时按防御反伤 |
| 不动明王身 | 绝学 | 护盾首次破裂时重获小护盾并强化本场反震 |

### 3.4 影身

| 武学 | 定位 | 核心效果 |
| --- | --- | --- |
| 踏雪无痕 | 起手核心 | 提高闪避，闪避后缩短下一次攻击间隔 |
| 惊鸿一式 | 暴击协同 | 每场首击必定暴击，后续提高暴击伤害 |
| 流云步 | 探索协同 | 同时提高移速、闪避和少量攻速 |
| 无相残影 | 绝学 | 每次闪避后立即发动一次较弱反击，反击可以暴击 |

### 3.5 血刀

| 武学 | 定位 | 核心效果 |
| --- | --- | --- |
| 饮血刀法 | 起手核心 | 提高吸血，击杀后额外恢复气血 |
| 血战八方 | 残血协同 | 气血越低攻击越高，设置 35% 的增伤上限 |
| 沸血诀 | 受击协同 | 受伤后短暂提高攻速，可独立刷新但不无限叠加 |
| 修罗血域 | 绝学 | 低于 50% 气血时吸血翻倍，并获得固定伤害加成 |

影身与血刀都必须保持自动触发，不增加手动释放技能，避免改变自动战斗核心。

## 4. 五种跨流派秘传

两条对应流派都达到累计 2 重时自动激活秘传，不占用升级选择。每种秘传拥有独立 icon，
并在构筑栏中显示点亮条件。

| 秘传 | 组合 | 效果 |
| --- | --- | --- |
| 青锋淬毒 | 快剑 + 毒掌 | 剑气命中额外施加 2 层毒 |
| 以毒养血 | 毒掌 + 血刀 | 毒伤恢复提高，溢出恢复转为少量护盾 |
| 血铸金身 | 血刀 + 铁壁 | 低于半血时提高防御，反震可获得少量吸血 |
| 虚实金钟 | 铁壁 + 影身 | 闪避成功时恢复少量开战护盾 |
| 无影追风 | 影身 + 快剑 | 暴击会推进一次剑气命中计数 |

首轮只实现其中 2 种，确认 UI 和战斗反馈可读后再补齐 5 种。

## 5. 江湖奇物与固定装备

### 5.1 奇物定位

奇物不占武器、护甲、饰品槽，每局最多持有 2 件。它们提供整局规则变化，是商店中
价格最高的商品类别。

| 奇物 | 规则效果 | 构筑方向 |
| --- | --- | --- |
| 寻龙司南 | 提前揭示附近两个洞穴的类型和奖励 | 路线规划 |
| 玲珑铁算盘 | 商店所有商品价格降低 15% | 铜钱经济 |
| 悟道蒲团 | 本局第一次武学升阶服务费用降低 | 武学成型 |
| 断剑穗 | 每场第一次剑气伤害提高 | 快剑 |
| 毒蟾玉 | 毒层上限提高 3 层 | 毒掌 |
| 镇岳铃 | 开战护盾提高并显示破盾预警 | 铁壁 |
| 影纹玉佩 | 每场第一次闪避失败保护为减伤 | 影身 |
| 血髓珠 | 低于半血时首次吸血效果翻倍 | 血刀 |

### 5.2 装备扩充方向

保留武器、护甲、饰品三个槽位。目标总量为 15 件固定装备，每条流派至少有 2 件明确
协同装备，剩余为通用补强。装备详情必须同时显示当前穿戴物和购买后的属性变化。

首批新增：追风剑、腐骨手套、玄武甲、夜行披风、饮血刀、淬毒针匣、镇岳护腕、
飞燕靴、赤心坠。现有青钢剑、轻鳞衣、练功护腕、玄铁戒、游侠披风、毒镖囊保留。

## 6. 云游商店商品结构

### 6.1 每次商店库存

| 分区 | 数量 | 生成规则 |
| --- | ---: | --- |
| 武学残页 | 4 | 2 个主流派、1 个互补流派、1 个随机 |
| 装备或奇物 | 2 | 至少 1 个与当前构筑有明确联动 |
| 即服丹药 | 2 | 至少 1 个回复类，另一个为成长类 |
| 重修服务 | 2 | 武学升阶、散功换诀各一次 |

库存进入洞穴时一次生成并固定。离开再返回不能重新抽取；已购买商品保留“售罄”位置，
帮助玩家理解商店结构。

每次商店随机指定一件八折商品。玩家可以买多件，但铜钱目标只支持一次高价购买或
两到三次中低价购买，使“买核心、买补给、还是整理构筑”形成机会成本。

### 6.2 价格带

| 商品 | 建议价格 |
| --- | ---: |
| 即服丹药 | 5–8 铜钱 |
| 普通武学一重 | 10–13 铜钱 |
| 已有武学升阶 | 12–16 铜钱 |
| 精良装备 | 14–18 铜钱 |
| 稀有装备 | 19–24 铜钱 |
| 江湖奇物 | 22–30 铜钱 |
| 散功换诀 | 14 铜钱，每次商店限一次 |
| 刷新未售商品 | 首次 6 铜钱，每次商店限一次 |

目标是玩家进入商店时通常持有 18–35 铜钱。若实测低于该区间，应调整铜钱掉落，不能
只把全部商品价格压低到失去取舍。

### 6.3 两种重修服务

- 武学升阶：从已学且未满重的武学中选一门，直接增加一重。
- 散功换诀：选择一门非起手、非绝学的一重武学移除，随后从其余流派起手核心中三选一。

散功换诀不是卡组删除的照搬，而是适配本项目小规模武学栏的构筑修正工具。选择前必须
展示“失去什么、获得什么”，并提供二次确认。

### 6.4 即服丹药

丹药购买后立即生效，不增加战斗内手动道具按钮：金疮药恢复气血、虎骨丸增加防御、
轻灵散增加移速、赤阳丹增加攻击、培元丹增加最大气血、悟道香提供修为。

## 7. 商店 UI

### 7.1 横屏 960 × 540

- 顶栏固定显示商人头像、简短对白、当前铜钱和“结束交易”。
- 左侧约 68% 为货架：第一行 4 个武学商品卡，第二行 2 个装备/奇物和 2 个丹药。
- 右侧约 32% 为选中商品详情、当前装备对比和两种重修服务。
- 商品卡使用 64 × 64 icon、名称、流派/类别角标、核心效果和价格。
- 鼠标悬停只切换详情；购买必须点击价格按钮，避免误购。

```text
┌ 商人头像 / 对白 ───────────── 当前铜钱 ─ 结束交易 ┐
│ 武学 1 │ 武学 2 │ 武学 3 │ 武学 4 │ 选中商品详情 │
│ 秘器 1 │ 秘器 2 │ 丹药 1 │ 丹药 2 │ 装备数值对比 │
│              刷新未售商品              │ 升阶 / 换诀 │
└───────────────────────────────────────────────┘
```

### 7.2 竖屏 540 × 960

- 顶栏固定显示商人头像、铜钱和退出按钮。
- 中部使用“武学 / 秘器 / 丹药 / 重修”四个分页，共用同一份库存状态。
- 商品使用两列卡片；详情在点击商品后从底部展开，购买按钮位于安全区上方。
- 切换分页、横竖屏或关闭确认弹窗时，选中商品和已售状态必须保持。
- 不把横屏的 8 个商品硬压进同一屏；竖屏允许滚动，但价格和类别始终清晰可见。

```text
┌ 商人头像 ─ 当前铜钱 ─ 退出 ┐
│ 武学 │ 秘器 │ 丹药 │ 重修 │
│      商品卡 1  商品卡 2     │
│      商品卡 3  商品卡 4     │
│         可滚动货架          │
│ 选中商品效果 / 联动 / 对比   │
│          购买按钮            │
└─────────────────────────────┘
```

### 7.3 商品状态

- 可购买：完整 icon 和暗金价格按钮。
- 铜钱不足：icon 降低饱和度，价格变朱红，仍可查看详情。
- 已购买：保留 icon 轮廓，覆盖独立“售罄”印章。
- 折扣：价格旁显示独立纸签，不把折扣文字画进 icon。
- 构筑联动：卡片显示玉绿色“已联动”角标，详情说明具体与哪门武学联动。
- 装备比较：用绿色上箭头、红色下箭头和数值同时表达，不能只靠颜色。

## 8. Icon 清单与规范

### 8.1 当前缺口

当前已有 6 个武学 icon、5 个装备 icon 和 4 个 HUD icon。正式商店前先补：

- 百毒心经、金钟罩、反震诀独立 icon。
- 毒镖囊独立 icon。
- 商店、刷新、升阶、散功换诀、折扣 5 个功能 icon。

### 8.2 计划资源量

| 批次 | 新增数量 | 内容 |
| --- | ---: | --- |
| A：修复现有缺口 | 9 | 3 武学、1 装备、5 商店功能 |
| B：扩展武学 | 16 | 2 个新流派 8 个、原三派绝学 3 个、跨派秘传 5 个 |
| C：装备与奇物 | 17 | 9 件新增装备、8 件奇物、毒镖囊已在 A 批 |
| D：丹药与洞穴 | 12 | 6 丹药、6 个主要洞穴类型 |

共计划新增 54 个独立 icon。所有 icon 先完成清单与稳定 ID，再分批生成，禁止一次生成后
再反向猜测图标对应内容。

### 8.3 目录与命名

```text
Assets/Art/Generated/Icons/
  Skills/       ico_skill_<id>_v01_128.png
  Equipment/    ico_equipment_<id>_v01_128.png
  Relics/       ico_relic_<id>_v01_128.png
  Consumables/  ico_consumable_<id>_v01_128.png
  Caves/        ico_cave_<id>_v01_128.png
  Shop/         ico_shop_<action>_v01_128.png
```

### 8.4 统一生产规格

- 256 × 256 透明母版，主体限制在中央 192 × 192 安全区。
- Unity 交付为 128 × 128 PNG；商店主卡显示 64 × 64，竖屏紧凑卡不小于 48 × 48。
- icon 内不烘焙名称、价格、重数、稀有度、折扣、售罄或流派文字。
- 武学强调动作和力量来源，装备画完整物件，奇物保持单个强轮廓，丹药使用瓶、丸、香等
  不同外形，洞穴图标强调入口轮廓和内部特征。
- 同批资源统一宣纸笔触、墨线重量、主体占比和光影方向。
- 流派同时使用颜色与轮廓：快剑为银白斜锋，毒掌为紫绿掌印，铁壁为金灰圆盾，影身为
  青蓝残影，血刀为暗红弧刃。
- 必须通过 64、48、32 px、灰度和常见色弱模拟检查。

## 9. 实现顺序

### S0：商店灰盒

1. 把当前固定三行商品改成配置化库存数据。
2. 实现横竖屏布局、8 件商品、铜钱不足、售罄、详情和装备对比。
3. 暂时复用现有 icon，只用于验证购买流程；不可标记为正式美术完成。
4. 实现库存固定、一次刷新和武学升阶服务。

### S1：构筑扩展

1. 实现影身、血刀各 3 门普通武学，绝学后置。
2. 扩充固定装备到每条流派至少 2 件。
3. 实现 2 个首批跨派秘传与 3 个首批奇物。
4. 商店生成根据当前主流派和副流派进行保底。

### S2：首批正式 icon

1. 先补 A 批 9 个现有缺口和商店功能 icon。
2. 再生产当前已经实现的新增武学、装备、奇物 icon。
3. 逐项完成 `Generated → Normalized → Imported → InEngineQA`，不能只以生成图验收。
4. 清除代码中百毒心经、金钟罩、反震诀和毒镖囊的图标回退。

### S3：完整构筑与平衡

1. 补齐 5 门绝学、5 个跨派秘传、8 个奇物和 6 种丹药。
2. 测试商店出现率、购买率、未消费铜钱和各类别购买优先级。
3. 若某类商品长期购买率低于 10%，先检查信息、价格和协同，再决定是否移除。

## 10. 验收标准

- 一次商店提供 8 个商品和 2 个服务，且至少 4 个商品与当前构筑相关。
- 玩家通常能买 1 件高价商品，或 2–3 件中低价商品，不能轻易清空商店。
- 每个商品都有独立 icon；不存在正式状态下的跨内容图标复用。
- 玩家在 3 秒内能分辨商品类别、是否买得起以及是否与当前构筑联动。
- 横屏 960 × 540 和竖屏 540 × 960 都能完成查看、购买、重修和退出。
- 商店、重修和确认弹窗期间所有时间暂停；退出洞穴后主地图时间恢复。
- 普通战斗主时间继续、洞穴主时间暂停、Boss 独立计时三条规则保持不变。
