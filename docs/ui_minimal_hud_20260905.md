# 竖屏探索 HUD 精简

## 本次实现

- 去掉独立关卡/铜钱横框、探索武学横框、“武学自动运转 / 磨砺”常驻说明。
- 左上角色卡高度 96：等级、铜钱图标与数值、气血条与数值、底边修为进度线。连同顶部边距，底边为安全区 y + 108。
- 原两条横框及说明占到安全区 y + 236；正常探索顶部信息纵深减少 128 个逻辑单位（540 × 960 的约 13%）。这不是全屏像素遮挡面积统计，右侧按钮和下方消息保留。
- 关卡名首次可操作探索显示 3 秒，之后在暂停页查看。磨砺升层显示 3 秒提示，角色面板保留完整层数和属性。提示不占用顶部路线区。
- 只在确有状态时绘制紧凑限时 Buff 徽条，复用原图标、倒计时和叠层；同时展示效果文字，无状态时不绘制空框。
- 战斗武学、冷却、触发反馈与危险预警不变；横屏仍沿用原布局。无手动释放技能按钮。
- 设计取舍按 game-design 的核心决策优先、mobile-games 的触摸/视野约束处理：探索时优先看路线与危险，完整构筑通过已有角色入口查看，不缩小原快捷按钮。

## Unity Editor 手动操作

无需创建 GameObject、挂载脚本、绑定 Inspector 或拖入 Prefab/UI 引用。沿用现有 HUD 引用与主题资源。

运行：打开 `Assets/Scenes/MainPrototype.unity`，Game View 选择 Portrait 540×960，进入 Play，进入关卡2并选择起手武学。

## 手动复验与未完成事项

1. 入场观察 3 秒提示退出，滑动移动检查原横框区域可用于观察路线。
2. 打普通敌人获得轻身，检查出现、叠层和退出；两次地图胜利后检查磨砺提示。
3. 点角色/设置，检查完整信息与暂停，继续后检查提示剩余时长。
4. 旋转横竖屏，检查气血、铜钱、武学和时间不重置。
5. 普通战斗/洞穴战斗/最终 Boss 检查上述三种时间语义。
