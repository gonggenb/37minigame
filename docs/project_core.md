# 项目核心约束

## 1. 项目定位

本项目是一款 1 分钟武侠 Roguelite 自动战斗游戏。

核心体验是：

玩家在极短时间内探索地图、遭遇敌人、自动战斗、获得武学和属性成长，然后挑战最终 Boss。

游戏重点不是长线大地图探索，也不是传统回合制 RPG，而是短局压力、路线选择、构筑成长和反复试玩。

## 2. 单局基础流程

单局流程如下：

1. 玩家进入普通地图。
2. 主地图 60 秒倒计时开始。
3. 玩家移动探索地图。
4. 地图中存在敌人、资源点、事件点、隐藏洞穴入口。
5. 玩家触碰普通敌人后进入自动战斗界面。
6. 普通战斗期间，主地图倒计时继续。
7. 战斗胜利后获得奖励，并返回主地图。
8. 玩家可以进入隐藏洞穴。
9. 隐藏洞穴内，主地图倒计时暂停。
10. 60 秒结束后，普通地图阶段结束；若玩家正在普通战斗，则先完成该场战斗。
11. 当前普通战斗及其升级选择结算完成后，玩家进入最终 Boss 战。
12. Boss 战独立计算，不受 60 秒主地图时间限制。
13. Boss 战结束后进入结算界面。
14. 玩家可以返回主页；存在已配置后续场景时也可以进入下一关。

首次新手流程在上述核心循环前增加固定关卡序列：

1. 首页进入关卡选择；关卡2初始锁定。
2. 选择关卡1后，先完整播放与最终 Boss 的前置对话。
3. 对话结束自动载入教学关卡；教学 HUD 提供“跳过”图标，可直接解锁并进入关卡2。
4. 教学场景加载完成且尚不可操作时，显示一次全屏提示“你只有30秒!”。
5. 玩家点击任意位置关闭提示，移动与 30 秒倒计时同时开始。
6. 教学地图只保留四个最小互动单位：南方药草、东方洞穴、西方宝箱、北方普通敌人；
   不使用箭头、高亮或强制任务。
7. 教学 30 秒结束后进入关卡总结，展示本关结果与构筑摘要；玩家可以返回主页或选择下一关。
8. 教学总结选择“下一关”后载入关卡2；教学 HUD 的“跳过”图标仍可直接进入关卡2，不经过总结。
9. 关卡2加载完成但尚不可操作时，固定显示一次“难度飙升！！！”提示；玩家点击关闭后，
   才进入起手武学选择与正式关卡流程。该提示按玩家存档只展示一次，之后不重复弹出。

教学完成状态作为关卡2解锁条件保存；之后玩家可以在关卡选择页重玩教学或直接进入关卡2。
使用教学 HUD 的“跳过”图标与自然完成教学使用同一解锁记录，都会进入同一个关卡2过渡流程；
首次进入时必须先确认难度提示，之后才进入起手武学选择。

每关结束统一进入结算阶段并冻结玩法操作。结算提供“返回主页”和“下一关”：只有通关且已配置
后续场景时才能进入下一关；当前关卡2是最后一关，因此其“下一关”入口显示为尚未开放。

## 3. 已确认时间规则

### 3.1 普通地图阶段

普通地图阶段有 60 秒主倒计时。

玩家需要在 60 秒内尽量提升战力，为最终 Boss 战做准备。

### 3.2 普通战斗阶段

玩家触碰普通敌人后进入自动战斗。

普通战斗期间，主地图 60 秒倒计时继续流逝。

这条规则非常重要，因为普通战斗本身就是一种时间消耗。玩家需要判断每场战斗是否值得。

若倒计时在普通战斗中归零，不中断或取消当前战斗。玩家完成该场战斗及其升级选择后再进入最终 Boss 战；普通战斗失败仍直接进入失败结算。

### 3.3 隐藏洞穴阶段

玩家进入隐藏洞穴后，主地图 60 秒倒计时暂停。

隐藏洞穴可以包含战斗、事件、奖励选择或特殊挑战。

初期隐藏洞穴要保持简单：进入洞穴，完成一场战斗或一个事件，获得奖励，返回主地图。

不要一开始把隐藏洞穴做成复杂副本系统。

### 3.4 最终 Boss 阶段

最终 Boss 战不受主地图 60 秒限制。

进入最终 Boss 战时，玩家气血恢复至满值。

Boss 战是独立阶段，可以单独统计 Boss 战时间、伤害、胜负和结算评价。

不得把 Boss 战塞回普通 60 秒地图倒计时内。

## 4. 设计目标

项目需要优先满足：

1. 单局短。
2. 节奏快。
3. 自动战斗。
4. 路线选择有压力。
5. 成长反馈明确。
6. 武侠味清晰。
7. 可反复试玩。
8. 系统可以后续扩展。

## 5. 武侠包装方向

推荐术语：

- 生命：气血。
- 能量：真气。
- 经验：修为。
- 技能：武学。
- 被动：心法。
- 高级技能：绝学。
- 货币：铜钱。
- 随机事件：奇遇。
- 隐藏房间：隐藏洞穴、秘境、山洞。
- Boss：强敌、魔头、宗师、守关人。

代码中可以先使用通用英文命名，但 UI 和策划表达应逐步靠近武侠语境。

## 6. 当前目标边界

当前优先做可玩的核心原型。

第一阶段不追求完整内容量、正式美术、商业化、联网或复杂局外养成。

判断一项需求是否该做时，先问它是否能帮助验证以下问题：

- 60 秒主循环是否有压力。
- 碰怪自动战斗是否顺畅。
- 普通战斗继续计时是否形成选择。
- 隐藏洞穴暂停计时是否有吸引力。
- Boss 是否能检验本局成长。
